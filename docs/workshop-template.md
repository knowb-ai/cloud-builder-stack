## Build Flow

1. Define the user problem.
2. Sketch the smallest useful workflow.
3. Wire the first API call.
4. Add orchestration.
5. Add UI or voice interaction.
6. Deploy or publish the demo.
7. Review cost, privacy, and security considerations.

## Safety Checklist

- `.env` is not committed.
- Demo keys are scoped and disposable.
- Public webhooks are disabled unless needed.
- Spend limits or quotas are configured.
- Attendee data is synthetic or approved for use.
- Screenshots and livestreams do not expose credentials.

## Wrap-Up Prompts

- What part of the stack created the most leverage?
- What would need to change before production use?
- Which credentials, quotas, or data policies should be revisited?
