# Backend

Use this directory for the FastAPI app.

Default responsibilities:

- API routes and page routes
- webhook endpoints
- auth callbacks and session handling
- provider SDK clients and service modules
- server-side secret usage
- static serving for a prebuilt frontend when deploying as one service

Keep browser-exposed code out of this directory unless it is static output generated by the frontend build.

## Run Locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload
```

Build `frontend/dist` before using the backend as the SPA server.
